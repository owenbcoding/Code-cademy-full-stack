# Web Development Foundations

This folder mirrors the first section of Codecademy's Full-Stack Engineer
career path. The modules are kept in course order:

1. Welcome to the Full-Stack Engineer Path
2. Fundamentals of HTML
3. Fundamentals of CSS
4. Developing Websites Locally
5. Deploying Websites
6. Improved Styling with CSS
7. Making a Website Responsive

Each module contains Markdown lesson notes. HTML and CSS modules also contain
small practice files that can be opened or edited directly.
