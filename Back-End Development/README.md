# Back-End Development

Practice prompts for the back-end topics in the Full-Stack Engineer path.
Each topic folder contains a `practice-*.js` file with three sections and
three examples per section.

## Topics

- Introduction to Back-End
- Build a Back-End with Express.js
- User Authentication & Authorization
- Back-End and Feature Testing
- Database Basics
- Working with Databases
- Designing Relational Databases
- Advanced PostgreSQL
- Adding a PostgreSQL Database
- API Development with Swagger and OpenAPI
- Portfolio Project: E-Commerce App (REST API)
