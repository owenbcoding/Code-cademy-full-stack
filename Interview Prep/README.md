# Interview Prep

Practice prompts for technical interviews, data structures, algorithms,
communication, and the final full-stack portfolio project.
Each topic folder contains a `practice-*.js` file with three sections and
three examples per section.

## Topics

- What To Expect in a Technical Interview
- Linear Data Structures
- Complex Data Structures
- Algorithms
- Search & Graph Search Algorithms
- Interview Skills
- Portfolio Project: Open-Ended PERN App
- Next Steps in Your Full-Stack Engineer Journey
