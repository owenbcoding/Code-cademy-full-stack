# Iterators

The iterator lessons belong with **JavaScript Arrays and Objects**, not with
Web Development Foundations. JavaScript array iterator methods run a callback
for each element:

- `forEach()` performs an action for every element.
- `map()` creates a new transformed array.
- `filter()` creates a new array containing matching elements.
- `find()` returns the first matching element.
- `reduce()` combines the elements into one result.

The examples and practice scratchpad for this topic are in `index.js` and the
root-level `practice.js`.
