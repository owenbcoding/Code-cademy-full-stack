# Building Interactive Websites with JavaScript

This section follows Web Development Foundations and groups the existing
JavaScript practice by the two JavaScript course parts.

The next accessibility section is kept inside this course folder at
`Making A Website Accessible/`, alongside the JavaScript parts.

The following course modules are organised in the root-level
`Front-end Development/` folder:

- `Front-end Development/JavaScript Syntax Part 3/`
- `Front-end Development/JavaScript Testing/`
- `Front-end Development/Async JavaScript and HTTP Requests/`
- `Front-end Development/React Part 1/`
- `Front-end Development/React Part 2/`
- `Front-end Development/Redux/`
- `Front-end Development/Git and GitHub Part 2/`

These new modules currently contain Markdown lesson notes only; practice code
will be added later.

## Part 1

JavaScript syntax, data types, variables, conditionals, functions, scope,
arrays, objects, and iterator methods.

## Part 2

DOM and events, asynchronous JavaScript and APIs, React/Redux reference
examples, and Node/Express/PostgreSQL reference examples.
