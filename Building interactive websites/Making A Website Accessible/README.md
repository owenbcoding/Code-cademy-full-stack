# Making A Website Accessible

This is the next section after Building interactive websites in the
Full-Stack Engineer path. It introduces practical accessibility (a11y)
patterns for making websites usable by more people.

## Modules

1. Web Accessibility Fundamentals
2. Semantic HTML for Accessibility
3. Accessible Forms and Controls
4. Accessible CSS and Visual Design
5. Testing Website Accessibility

Each module contains lesson notes and a prompt-only
`practice-[lesson-name].js` worksheet with three sections and three examples
per section.
