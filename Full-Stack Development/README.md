# Full-Stack Development

Practice prompts for connecting front-end and back-end development, securing
applications, understanding operating systems, and deploying full-stack apps.
Each topic folder contains a `practice-*.js` file with three sections and
three examples per section.

## Topics

- Connecting Front-End to Back-End
- Deploying Web Applications
- Web Security Fundamentals
- Data Security
- Common Attacks on Web Applications
- Fundamentals of Operating Systems
- DevOps Fundamentals
- Portfolio Project: E-Commerce App (Client)
